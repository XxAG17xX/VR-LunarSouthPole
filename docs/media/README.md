# README Image Sources

Everything here is either an original project capture or built directly from one. Nothing
is AI-generated, and no capture has been retouched. These are simulation captures, not lunar
photographs, and they document the April 2026 version, not necessarily the latest repo state.

## Original captures (April 13, 2026 collection)

Supplied by Kartik Gupta and copied byte-for-byte, without cropping or colour changes. All
source filenames begin with `com.UnityTechnologies.com.unity.template.urpblank-20260413-`.

## Built from the captures

`hero.jpg` (1280x480) and `social-preview.jpg` (1280x640) place `lander-earth.jpg` on a
black canvas with a fade on its right edge and add the project title in Exo 2 (SIL Open Font
License). The capture itself is not altered. `social-preview.jpg` is the image GitHub shows
when the repository link is shared.
