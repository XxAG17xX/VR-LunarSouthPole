# Models Intentionally Omitted

This folder originally held the following models used during the capstone:

- Apollo Eagle lunar lander (`Eagle_lander/`).
- Orion crew capsule interior (`Orion_Interior/`).

These assets were supplied privately for the academic project and are not
licensed for public redistribution. The models, associated textures, materials,
and Unity metadata are intentionally excluded from this public repository.
There is no public download link provided here.

The scene and some setup scripts still reference these assets. A fresh clone
will therefore have missing references until you provide appropriately licensed
replacements and update the scene. Pulling Git LFS objects will not restore the
omitted assets. This repository is a project showcase and source archive, not a
self-contained, ready-to-build distribution.

Local authorised working copies can remain in the original folders, which are
excluded by the root `.gitignore`. Do not force-add them to Git.
